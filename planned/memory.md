## 🔧 Key Technical Decisions

| Decision | Choice | Rationale |
|---|---|---|
| **Temporal PE** | Sinusoidal (Transformer-style) | Avoids sparse gradients from 49 learned vectors with few samples per step |
| **Edge selection** | Gumbel-softmax (differentiable) | Gradients flow from D → EdgePredictor → G (genuine adversarial training) |
| **Discriminator** | Dual-head: MLP + mini-GraphSAGE | Core novelty — Head B is adversarially trained (not a fixed filter like THG-OAFN) |
| **Normalisation** | Per-timestep z-score | Feature distributions drift across timesteps; global norm leaks temporal info |
| **Train splits** | ts 1–29 / val 30–34 / test 35–49 | Standard Elliptic protocol; comparable to published baselines |
| **D stability** | Spectral normalisation on all D linears | Prevents D from becoming too powerful, causing G mode collapse |
| **D label smoothing** | 0.1 (one-sided) | Reduces D overconfidence without harming training signal |
| **GAN training** | Alternating, D×2 per G×1 | Standard DCGAN best practice; D needs a head-start |
| **Augmentation ratio** | Sweep 10/20/30% | 20% is primary; over-augmenting can hurt precision |

## ⚠️ Errors & Fixes

- **`BASE_DIR` Path Issue**: `models_save_dir` was appending `graphguard/models` twice, causing `FileNotFoundError`. Fixed by using `MODELS_DIR` directly.
- **NaNs in features**: Standardizing features with zero variance per timestep caused NaNs. Fixed by using `torch.nan_to_num(X, nan=0.0)` in the dataloader.
- **Discriminator Gradient Bug**: `fake_struct_stats` leaked gradients across `D_STEPS` causing a graph free error. Fixed by adding `.detach()` and using `loss_D.backward(retain_graph=True)`.
- **Softmax `-inf` NaN Bug**: Masking candidates with `-inf` in `EdgePredictor` caused `NaN` if all candidates were masked out by the temporal check. Fixed by changing `-inf` to `-1e9`.
- **Missing `numpy`**: Added missing `import numpy as np` in plotting cell.

## 🐛 Known Risks & Mitigations

| Risk | Mitigation implemented |
|---|---|
| GAN mode collapse | Spectral norm on D, feature matching loss, label smoothing |
| Gumbel-softmax instability | Temperature annealing (1.0 → 0.1), top-k straight-through fallback |
| PyG not available | Pure-PyTorch ManualSAGEConv fallback in all model files |
| No dataset on first run | Explicit error messages with Kaggle download instructions |
| Memory overflow (large graph) | Candidate pool capped at 512, batch size 32 |
